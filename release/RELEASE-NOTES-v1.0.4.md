# v1.0.4

- NAS 主服务与普通 CPU 分离镜像支持 amd64／ARM64，同一个标签自动匹配架构；32 位 ARM 不支持。
- CPU 分离镜像补齐 SoundFile 音频读写后端。
- Intel NPU 仍仅支持 amd64；ARM64 可使用 PC、CPU 分离或外部 API。
- 已安装 v1.0.3 APK／PC 的用户无需因 ARM 支持单独更新客户端。

- B站 4K60 下载：修正接口 62.5 fps 标注导致的失败，保留真实分辨率和独立音轨校验。
- 登录维护：新扫码保留刷新令牌，按需自动更新；维护失败保留现有登录，支持重试和并发保护。
- Android：当前歌曲后台预取至临时磁盘缓存，结束／切歌后清理；短暂请求失败不打断有效租约。
- NAS NPU：恢复可选 Intel OpenVINO htdemucs 分离，附同版本 Compose，PC → NPU → 外部 API 后备。
- 曲库：编辑旁直接移出；勾选后可批量找封面、补歌词和移出。歌词候选高亮，提供明确保存按钮。

NAS 与 APK 均需更新才能获得全部变化；PC 可继续沿用。更新保留原数据映射和配置。NPU 是实验功能，需独立设备与驱动；当前本机验证未覆盖真实 NAS NPU 和平板／电视长期播放。

本地验证：208 项 Node 测试通过，1 项 Linux 专用测试跳过；35 项 Android 单测、lintDebug 和 APK 构建通过；4 项 NPU 算法／检测测试通过；相关浏览器回归和前端构建通过。
