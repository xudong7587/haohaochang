# 好好唱 v0.3.12

## 电视自动连接与启动修复

APK 首次启动约用 8 秒寻找同一局域网的 NAS，找到后直接进入扫码页；多个歌房可选择，未找到可手动输入地址。连接、选址和扫码页面重新设计，支持遥控器焦点与重试。

修复已复现的旧 WebView 登录后白屏问题，增加兼容脚本、加载超时和启动失败提示。NAS 与 APK 需要同时升级。自动发现使用 UDP 43212，LAN Compose 已开启；原 LAN 配置的 `KTV_DISCOVERY_ENABLED=1` 同样有效。桥接、访客 Wi-Fi 或跨网段可能收不到广播，可继续手动连接。

## 歌星资料、封面与播放界面

- “歌星管理”支持照片和介绍编辑，可获取歌手图、搜索 B站图片或上传。详情页展示大图、介绍与歌曲瀑布流，点击歌曲打开完整编辑器，另有原唱试听。
- play／TV 的“歌星点歌”展示同样资料，点击歌曲直接加入队列；歌曲墙、队列与分页统一深色。
- 歌曲封面自动居中裁成方形并铺白底，修复旧 FFmpeg 透明图片处理失败。由 NAS 完成，不需要 PC；失败保留旧封面和音轨。
- TV 舞台与全屏播放中，歌词按钮闲置 4 秒隐藏；按键、触摸或鼠标移动唤回，暂停或错误时保留显示。
- 同一个 APK 支持 Android 手机本机播放，适配横竖屏并保持播放页面。仍连接 NAS，共用曲库与队列，电视保留播放优先权；扫码 `/mobile` 继续只做遥控点歌。

自动照片可能回退到同歌手专辑图，可以手动替换。自动短介绍仅采用 Wikidata 中同名且唯一的演唱者条目并保留来源，无法可靠匹配时保留空白或手写介绍。

## 更新与验证

更新 NAS 镜像并重建容器，保留密码、端口与三个目录映射；电视菜单中检查应用更新，或手动安装附件 APK。手机可安装同一个 APK。PC 包同步版本，此次封面和歌星资料功能不依赖 PC 更新。

本地 143 项 Node 测试、生产构建与浏览器联动检查通过，新增检查覆盖歌星编辑和点歌、手机双方向布局、闲置按钮唤回、实际旧浏览器备用脚本和启动恢复。正式 APK 与 Docker 容器验证结果见本次 Actions；Docker 校验包含实际 NAS FFmpeg 的透明图片保存与音轨不变检查。
