# v0.4.6 · TV 操作微调与本地曲库整理

先更新 NAS/Docker，再覆盖安装 TV APK。沿用原生 Media3 / SurfaceView 播放，手机点歌与在线找歌流程保留。

- TV 点歌面板遮罩改为 30% 不透明度，字母使用更大的纯文字，清空改为垃圾桶。歌曲默认按歌名排序，可切换随机，每次切换重新打乱一次。
- 已点歌曲短按优先表示当前歌曲结束后优先播放；长按仍弹出删除选项。
- 普通模式左下角常驻二维码，多个手机共享同一歌单；底部播放按钮居中，歌词调整数字向中间收拢。
- 歌词保留 0.5／3／10 秒步长及数字下方箭头，累计偏移不再限制 ±30 秒，按歌曲保存。
- 待整理与半标准条目增加直接删除；本地歌曲支持同名 NFO 识别、按歌名补齐歌手、重命名并移动至 download/半标准曲库，再由用户确认入库。含糊的歌手候选留待核对，正式资源可用后清理下载区源文件。
- 在线找歌、下载与处理沿用原流程；备用 AI 设置添加阿里云、腾讯云及 Replicate API 文档与适配说明。

下载 `haohaochang-tv-v0.4.6.apk`、`haohaochang-nas-v0.4.6.zip`。PC 包与独立重命名工具同步为 v0.4.6，手动覆盖时保留配置、模型和数据。
