# 好好唱 0.1.0 实机测试

源码仓库：https://github.com/xudong7587/haohaochang 。仓库及镜像已公开，NAS 无需登录即可拉取。

把本测试包中的 `compose.yaml` 和 `.env.example` 放到 UGOS 的 Docker 项目目录。将 `.env.example` 改名为 `.env`，修改：

```dotenv
KTV_IMAGE=ghcr.io/xudong7587/haohaochang:latest
SEPARATOR_IMAGE=ghcr.io/xudong7587/haohaochang-separator:latest
MEDIA_PATH=/volume1/media/ktv
ADMIN_TOKEN=替换成至少12位的管理密码
PUBLIC_URL=http://你的NAS局域网IP:3210
SEPARATION_API_KEY=
```

`MEDIA_PATH` 必须改成歌曲目录的实际路径。容器内该目录为 `/media`，只读挂载。`data` 自动存储于 Compose 目录下。

在 UGOS Docker 的“项目”中导入本目录的 Compose 并启动即可，不需要配置镜像仓库账号。也可通过 SSH 执行：

```sh
docker compose pull
docker compose up -d
docker compose ps
```

后台：`http://NAS-IP:3210/admin`。登录后扫描曲库。第一次先选择一首本地视频，配置正确的原唱/伴奏音轨，并准备播放。

电视安装包：`haohaochang-tv-0.1.0-debug.apk`。用 U 盘或已授权的 ADB 安装；进入应用填写 `http://NAS-IP:3210`，再用上述管理密码登录。遥控器菜单键可重新设置地址。

手机连接同一局域网，扫描电视二维码点歌。建议先验证本地播放、原唱切换、手机点歌与掌声，再打开在线搜索和 AI 功能。

可选的本地 AI 服务：

```sh
docker compose --profile ai-local pull
docker compose --profile ai-local up -d
```

后台 AI 地址填 `http://separator:8000`，模型填 `htdemucs`；设置过 `SEPARATION_API_KEY` 时两边密钥保持一致。首次模型下载及 CPU 分离需要等待。主服务测试不需要启动该容器。

查看故障：

```sh
docker compose logs --tail=100 ktv
docker compose --profile ai-local logs --tail=100 separator
```

这是 debug 签名的家庭测试 APK。WebView 需要现代 Chromium 支持；实际电视解码兼容性和遥控器键值需要此次现场测试。镜像为 `linux/amd64`，适用于当前这台 Intel NAS。
