# 好好唱 v0.3.7 · 实机快速开始

本版请同步更新 NAS 和 PC 整理器。已有歌曲在曲库管理 → 标准曲库点击“老版本多视频合一”，播放中或排队中的歌曲会跳过；空闲后可再次点击。画面默认保留原编码，不再自动转码。

1. 更新NAS镜像、PC整理器和TV APK。保留原密码、端口、data、downloads和media目录映射，不要启动两套服务共用数据库。
2. Linux NAS需要自动连接PC时使用docker-compose.lan.yaml；docker-compose.yaml用于桥接/手动连接。修改管理密码、端口和目录映射后启动。镜像为linux/amd64。
3. 打开NAS的/admin管理端，在“在线找歌”扫码登录B站；原有过期Cookie不会自动恢复。在线下载与收藏夹同步共用账号。
4. 电视安装本次APK、填写NAS地址。手机扫描电视登录二维码，验证管理密码并确认连接码，电视自动登录，手机继续点歌；已登录手机只需确认。后续普通点歌二维码仍可直接加入歌房。
5. 返回键先关闭弹层/全屏，再回到主界面；2.5秒内连续按两次返回退出APK。菜单键修改NAS地址。本次涉及原生返回处理，需要更新APK。
6. PC先停止旧整理器，再用haohaochang-resource-ai.zip覆盖程序，保留worker.json、runtime和data。打开start.cmd，在NAS启用AI分离和自动发现；/pc页面查看状态。
7. 在线预览选择清晰度、标记区间并加入曲库。新版下载独立视频和音频，保留实际分辨率，不能用低清冒充高清；实际档位仍取决于账号权限和片源。
8. 已有在线低清歌曲可在曲库使用“升级高清画面”，保留原裁剪区间、原唱、伴奏和歌词；无需重新分离。缺少可信来源记录时，使用替换画面流程并核对录音版本。
9. 无歌词时播放器不显示补充提示。自动校准只在多句与人声起点匹配时应用，曲库可恢复原歌词；仍可手动提前/延后0.5、3、10秒。

详细步骤见本包“四端使用说明.md”，或[在线使用手册](https://github.com/xudong7587/haohaochang/blob/main/docs/USER-GUIDE.md)。

已验证：本机隔离环境完成真实B站1080p下载、原区间裁剪、分轨与保留分辨率测试，以及手机/电视扫码联动浏览器检查。真实NAS升级、家庭PC歌词对齐质量与TV遥控器操作需安装后实机验收。

跨设备不能填写127.0.0.1；公司本机测试使用KTV_LOCAL_ONLY=1并关闭LAN发现。切换host网络前停止旧容器，保留数据。升级前备份data与曲库；失败会保留此前可用资源，不要手动删除版本目录。

APK为debug测试包。若提示签名不一致，记录原连接地址后处理旧测试包；更新后可重新扫码连接。
