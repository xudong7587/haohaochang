# 好好唱 0.1.0 实机测试

镜像和 APK 已公开下载，无需 GitHub 账号，也不用配置 .env。

1. 在 UGOS Docker 中创建项目，粘贴本包中的 docker-compose.yaml。
2. 修改 ADMIN_PASSWORD 管理密码（至少 12 位）、左侧宿主机端口、/data 左侧持久化路径、/media 左侧实际曲库路径。不要修改容器内 /data、/media 和右侧 3210。
3. 拉取并启动。后台打开 http://NAS-IP:你设置的端口/admin。
4. 输入管理密码。其余设置全部在后台完成，系统自动写入持久化目录中的 settings.json，无需手工新建文件。
5. 电视安装 haohaochang-tv-0.1.0-debug.apk，填写同一个 NAS 地址并登录。菜单键可重新设置地址。手机扫描电视二维码即可点歌。

若旧版部署提示 `all predefined address pools have been fully subnetted`，将本包新版 Compose 中的 `networks` 段加入原项目后重新部署，保留原有密码、端口和目录。新版显式使用容器子网 `10.253.231.0/24`；若提示 `Pool overlaps` 或与局域网/VPN 重叠，需换成未占用的私有子网。电视仍填写 NAS 地址，无需修改 NAS 网络或删除其他容器网络。

先用本地视频测试伴奏、原唱切换和手机点歌；双音轨须根据实际文件配置。再测试纯音频 + LRC、在线搜索及 AI。APK 是家庭测试签名版，电视需具备现代 WebView。

可选本地 AI 服务使用单独的 docker-compose.ai.yaml，与主文件合并启动：

```sh
docker compose -f docker-compose.yaml -f docker-compose.ai.yaml up -d
```

然后在后台填写 AI 服务地址 http://separator:8000、模型 htdemucs，API Key 留空。首次模型下载和 CPU 推理需要等待。第三方 AI 用户只需在后台填写兼容服务的信息，无需启动此容器。

更新主服务：

```sh
docker compose pull
docker compose up -d
```

故障日志：

```sh
docker compose logs --tail=100 ktv
```
