# 好好唱 v1.1.0 · 安装与快速检查

1. 按《NAS安装与升级.md》选择 x86 或 ARM64 Compose，沿用原项目、密码、端口和目录，启动主程序与独立分离容器。
2. 管理页打开“人声分离”，确认 CPU 已连接、PC 与 NPU 状态符合实际设备。地址与鉴权自动配置。
3. 使用自有或已授权的测试文件，分别确认 PC 优先、NPU 不可用时转 CPU，以及失败后已有资源保持可用。
4. 第一次 CPU 分离会下载模型；Intel NPU 首次检测和编译可能需要等待。缓存继续保存在旧 data 目录。
5. 安装本版 APK，检查歌手照片铺满卡片、单次触屏响应、横竖屏和电视遥控操作；浏览器 /play 同样检查照片四边没有空条。
6. 核对原曲库、队列、歌房和 PC 配置。之后日常只拉取、重建 ktv，不重建两个分离容器。

NAS 和 APK 需更新才能获得本版改动。现有 PC 整理器仍兼容，本包同时提供新版 PC 和重命名工具附件。生产 NAS 的实际 NPU 设备访问和音质仍需部署后确认。
