# 好好唱 v0.3.8

- 自动歌词按歌名、歌手匹配，已知时长允许相差最多两分钟，不再因为录音版本标签不同而拒绝；缺少时长也不会单独阻止匹配。多个候选优先选时长最接近的结果。歌词来源仍为本地索引与 LRCLIB。
- play 页面、TV 舞台和全屏增加“隐藏歌词／显示歌词”。关闭滚动歌词时同时隐藏倒计时和微调栏，只保留原有音视频播放；不会暂停、重载音轨或修改歌词文件。选择在当前设备保存，切歌和刷新后保留。

本地 111 项 Node 测试、前端构建及在线／播放器浏览器检查通过，覆盖匹配边界、隐藏后刷新、全屏开关和不中断音频播放。

更新 NAS 后刷新 play 页面或重新打开 TV 页面即可使用。PC 整理器没有功能改动，不要求从 v0.3.7 重装；APK 同步提供 v0.3.8。v0.3.7 已发布，因此本次使用新版本号，不覆盖旧安装包。
