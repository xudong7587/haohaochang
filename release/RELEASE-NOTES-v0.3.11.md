# 好好唱 v0.3.11

## 封面可以预览、选择和替换

“编辑歌曲 → 歌曲资料”现在显示当前封面。可以去 B站搜索，修改关键词、翻页并从多张视频封面中选择；也能手动上传不超过 8 MB 的 JPG、PNG 或 WebP。

已有封面同样能换。选中图片后先预览，点击“保存封面”生效，取消选择或上传失败保留旧图。透明图片铺白底保存，保持画面比例。B站搜索只获取封面，不下载或关联视频，不修改原唱、伴奏和歌词。

## 中文歌词新增 QQ 音乐和网易云音乐

自动选择依次尝试本地索引、QQ 音乐、网易云音乐、LRCLIB；编辑器也可指定来源。手动查找展示歌手、录音版本、专辑和时长，支持预览后选择。多份候选、不同演唱者或版本不会直接覆盖草稿，最后保存才替换歌词。自动整理仍保留歌名、歌手及时长检查。

实测已从 QQ 音乐取得周深《沉默的羔羊 (Live)》的同步歌词；LRCLIB 当前同名搜索没有周深版本。网易云接口处理与失败后备已通过自动测试，当前公司网络连接被重置，真实连接尚未通过验收。

## 更新与验证

更新 NAS Docker 镜像即可获得封面与歌词功能，保留密码、端口和目录映射。TV／PC 安装包同步到 0.3.11，保留 0.3.10 的应用内更新能力；已有 0.3.10 可使用更新入口，从 0.3.9 或更早版本则手动安装当前最新版一次。TV 旧 debug 签名冲突时卸载重装并重新登录。

本地 137 项 Node 测试、生产构建、曲库、海报和新增编辑器浏览器检查通过。覆盖已有封面替换、上传／取消、无效文件保护、只读预览禁写、移动端布局、歌词来源与候选选择。正式签名 APK、CI 与 Docker 镜像启动检查结果见本次 Actions。未自动部署到真实 NAS。

附件包含 NAS 配置包、PC 整理器、TV APK、独立重命名工具与 SHA-256 校验清单。详细步骤见[使用手册](https://github.com/xudong7587/haohaochang/blob/main/docs/USER-GUIDE.md)。
