# 好好唱 v1.0.0

本次为稳定版，更新 Docker 后台与 play 网页；不包含 NPU RC 实验功能。

- 修复在线找歌把清晰度上限当成下限、沿用旧预览高度导致的下载失败。最高可用画质不设 720p 门槛，支持 480p 等老 MV；仍校验实际视频流、音轨、帧率及文件完整性。
- play 全屏改用 TV 风格小图标，歌词开关在左，原唱／暂停／切歌集中，退出全屏在右；焦点提示自动消失。
- 歌词微调保留 0.5、3、10 秒，左延后右提前，数字下方显示箭头，左右键每次 0.5 秒，偏移继续按歌曲保存。

## 升级

保留现有 Compose、目录映射、密码和配置，拉取 `ghcr.io/xudong7587/haohaochang:1.0.0` 或 `:latest` 后重建主服务。网页刷新即可使用新控制栏；已有 v0.4.6 TV／PC 可继续使用，1.0.0 客户端仅统一版本号。

NPU 测试用户继续使用独立 `0.4.6.rc1` 主服务和 NPU 分离器标签。稳定版恢复 PC 连接器优先、外部 API 后备；不推广 NPU 镜像。
