# 好好唱 v0.4.0

需同步更新 NAS、TV APK 和 PC 整理器；旧 APK 热更新网页后也能使用新菜单，但原生播放必须安装新 APK。

电视播放改用 Media3 与 SurfaceView。画面、原唱和伴奏使用共同播放时钟，网页继续显示点歌界面、歌词及菜单。全屏“播放信息”可查看分辨率、帧率、解码器、缓存与累计丢帧。

歌星歌曲卡片统一高度，缺海报时保留占位。向右进入内容后收起左侧菜单，返回恢复主菜单焦点。全屏按钮移到切歌右侧；小窗不显示歌词微调。全屏返回键呼出或收起控制菜单，选择“退出全屏”才关闭。聚焦按钮使用白底、深色文字与光效。歌词微调自动按歌曲保存到 NAS。

歌曲编辑可查看 B站原始链接，从原链接更新，按歌名／歌手搜索或粘贴新链接。只有同一链接、同一分 P、前后都确认未裁剪且双音轨可用时，才仅更新画面；其他情况重新生成原唱、分离伴奏和匹配歌词，整套验证后替换。失败保留旧资源，新录音的歌词偏移归零。

普通入库保留原编码、4K、高帧率与 HDR。同分辨率下载优先高帧率。显式兼容转换与裁剪自动选择 NVENC、Quick Sync、AMF 或 CPU，保持原尺寸与帧率；HDR 转为 SDR。新版 PC 接受最多 4 GB 视频。

附件统一使用 `haohaochang-tv-v0.4.0.apk`、`haohaochang-resource-ai-v0.4.0.zip`、`haohaochang-nas-v0.4.0.zip`、`haohaochang-preprocess-v0.4.0.zip` 和 `SHA256SUMS-v0.4.0.txt`。旧版 TV／PC 更新器写死固定文件名，因此本次请手动下载更新一次。新版可在应用内识别后续版本化附件。正式 APK 沿用持久签名；PC 覆盖时保留配置、环境、模型与任务。

本地检查及未验范围见 [验证记录](https://github.com/xudong7587/haohaochang/blob/v0.4.0/docs/VALIDATION-v0.4.0.md)。真实电视上反馈歌曲的流畅度、HDR 输出和各品牌硬件编码器尚未验收，未部署生产 NAS。
