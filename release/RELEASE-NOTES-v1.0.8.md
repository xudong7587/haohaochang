# v1.0.8 · 点歌精简、手机显示与视频任务进度

## 这次更新

- 拼音首字母直接点歌，放大镜展开精确搜索，排序放到字母区下方；去掉字母背景卡，退格用左箭头、清空用垃圾桶，歌星照片改为圆角矩形。
- 点歌层取消整体暗色遮罩，卡片保留深紫渐变。Android 修正触屏要点两次、图标拉伸和顶部黑条，竖屏视频居中放大填满播放区域，横屏显示完整画面。
- 新打开播放端接续已点歌曲，无人点歌时保存随机轮次，尽量播遍可用曲库，新入库歌曲有更高优先级；手动暂停不受普通心跳影响。
- 在线找歌只保留视频流程，移除先找音频、失败转音频、登录检测状态和历史任务列表。搜索框下方只显示当前下载／转换进度，没有任务时隐藏。
- GitHub 仓库改名为 `haohaochang-KTV`，README 从曲库管理、自动图片与歌词、PC GPU／Intel NPU 分离和多端接入介绍项目。

## 如何更新

1. NAS 拉取 `ghcr.io/xudong7587/haohaochang:1.0.8` 或 `latest`，重建原容器，保留原目录、管理密码和端口。镜像地址不变。
2. TV／Android 手机／平板安装 `haohaochang-tv-v1.0.8.apk`，同签名覆盖保留登录；手机改进需要安装本版 APK。
3. 现有 PC 整理器仍兼容。要同步新版下载链接，等任务完成并退出后，用 `haohaochang-resource-ai-v1.0.8.zip` 覆盖，保留 `worker.json`、`runtime`、`.venv` 和 `data`。
4. NAS 配置包为 `haohaochang-nas-v1.0.8.zip`，独立重命名工具为 `haohaochang-preprocess-v1.0.8.zip`。仓库改名不改变安装包命名或数据映射。

浏览器可能要求点击一次才能有声自动播放。竖屏填满会裁掉视频两侧，横屏可查看完整画面。空闲的在线找歌页不显示任务历史，失败和已完成任务仍可在后台管理。
