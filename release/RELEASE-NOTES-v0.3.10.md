# 好好唱 v0.3.10

这一版加入 TV／PC 应用内更新、Windows 状态窗与托盘，并完善手机找歌、曲库浏览和歌词编辑。

## 本版变化

- TV 遥控器菜单可检查并下载新版，校验完成后打开系统安装器。正式 APK 开始使用持久签名。
- PC 原生窗口显示 GPU、显存、CPU、内存与任务，关闭窗口后留在托盘。窗口、托盘、PC 详细页面和 NAS `/pc` 均提供更新入口；下载校验后等待任务完成，备份程序、重启，新版启动失败恢复旧程序。
- 手机可从 B站预览选片段，整理好后自动点歌；没有合适视频可先找音频与歌词。手机请求优先排队，视频整理失败可后备找音频，页面可查看进度。
- 曲库默认展开歌曲，支持带封面的列表和海报瀑布流；每首只留一个编辑入口，操作反馈显示在编辑弹窗里。
- play／TV 卡片改为深色；缺少专辑图片时尝试匹配歌手照片或同歌手专辑图片。
- 歌词匹配兼容 Live 后缀及合唱署名顺序；手动查找遇到时长不同会提示核对，网络失败和无匹配结果分别反馈。隐藏系统歌词适用于 play／TV 和全屏，视频自带字幕仍保留。
- README 按安装和日常使用重写，补齐四端手册，CI 检查各端与文档版本一致。

## 安装与升级

- NAS：下载 `haohaochang-nas.zip` 或拉取 `ghcr.io/xudong7587/haohaochang:v0.3.10`；保留原密码、端口与目录映射，手动重建容器。自动发现使用独立的 LAN Compose。镜像为 Linux amd64。
- TV：首次手动安装 `haohaochang-tv.apk`。旧 debug 包如提示签名冲突，需要卸载旧包再安装，并重新填写 NAS 地址、扫码登录；从本版起可使用应用内更新。
- PC：首次退出旧整理器后，用 `haohaochang-resource-ai.zip` 覆盖程序，保留 `worker.json`、`runtime`、`.venv`、`data`，再运行 `start.cmd`；后续使用更新按钮。
- `haohaochang-preprocess.zip` 是独立的 Windows 重命名工具；`SHA256SUMS.txt` 提供四个下载文件的校验值。

PC 更新备份用于程序替换或启动失败恢复；断电、磁盘故障后的自动恢复尚未实现。TV／PC 更新需要能访问 GitHub。

## 验证范围

本地 130 项 Node 测试（含真实 FFmpeg）和前端构建通过，浏览器覆盖曲库、手机、歌词显示、PC 更新入口与 TV 播放接管。PC 更新测试使用临时目录与 localhost 子进程验证升级成功及失败恢复，不修改家庭设备。Android 构建、签名包与镜像构建结果见本次 Actions。

真实 NAS 未自动部署，TV 安装／遥控器和家庭 PC 模型任务仍需实机验收。完整步骤见[使用手册](https://github.com/xudong7587/haohaochang/blob/main/docs/USER-GUIDE.md)。
