# v1.0.5 · 后台任务与内存记录小修复

- NPU 地址提示按 host、桥接和配套 LAN 映射分别说明，不再固定暗示使用 8001；已有地址不自动改写。
- 旧资源回收先做只读预检，确有可回收资源才创建任务，空检查不再刷任务列表；已排队任务不重复创建。
- 保留播放、已点队列和处理中资源的保护；后续产生旧资源时仍会自动回收。已有完成记录保留。
- 下载目录监控释放已移走文件的记录，避免长期积累。不强制清除 Linux 文件缓存，也不更改容器内存限制。
- 主服务与 CPU 分离镜像继续支持 amd64／ARM64；Intel NPU 仍为 amd64。

已有部署只需更新主服务：拉取 ghcr.io/xudong7587/haohaochang:1.0.5（或 latest）并重建原主容器，保留原数据、媒体、下载映射及 NPU 地址／密钥。已有 v1.0.4 APK、PC 与 NPU 容器可继续使用，无需为这次修复升级。新部署仍提供同版本全套安装包。

NAS 实机内存排查中，主进程约 177 MiB，Docker 约 538 MiB 的读数主要包含文件缓存；本次优化不承诺将该缓存数字立即降低。
