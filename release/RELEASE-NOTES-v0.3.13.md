# 好好唱 v0.3.13

## 连续播放，不再反复校时

删除播放器每 100 毫秒检查音画差、超过 120 毫秒就跳转进度的逻辑。视频开始播放后交给设备连续解码，允许小幅音画差；只在开始／恢复播放、主动拖动进度、切换音轨或错误后备时对齐一次。歌词仍读取音频时间显示，不会更改视频进度。

NAS 沿用 HTTP Range 文件直读：分别提供画面、原唱和伴奏地址，由播放设备解码，播放时不在 Docker 上实时转码。原始画面编码与清晰度保持不变。歌词动画独立刷新，不再带动播放器菜单、二维码和队列每秒重绘约 30 次。

## 全屏遥控菜单

全屏下按遥控器“下键”或“确认键”打开底部控制菜单，并自动聚焦暂停／继续按钮；随后用方向键选择、确认键操作。菜单包含原唱／伴奏切换、切歌、歌词显示与时间调整、退出全屏。第一次唤醒或长按唤醒键不会误暂停或退出全屏，闲置 4 秒后隐藏，暂停时保持可见。

APK 使用已有沉浸式窗口内的全屏布局，保留视频、歌词与控制菜单在同一个 WebView，避免系统全屏视频层遮住菜单。

## 更新与验证

曲库新增“全选（所有分页）”，覆盖当前分类及搜索结果；顶部“补充全部缺失歌词”覆盖整个未隐藏曲库，也支持仅补充所选歌曲。任务在 NAS 后台执行，已有歌词保留。播放队列内或正在整理的歌曲会跳过，结束后可再次提交；查找失败可在整理任务中查看原因和重试。

本次主要修复随 NAS 网页更新生效，已有 v0.3.12 APK 可直接使用；APK 与 PC 安装包同步到 v0.3.13。升级 NAS 时保留密码、端口和三个目录映射。

本地 147 项 Node 测试、生产构建与播放器浏览器检查通过。新增测试覆盖播放中没有周期校时、慢画面不被自动跳转、错误后备保留时间、真实 HTTP 206 分段读取、全屏菜单唤醒与遥控操作。播放器回归包含真实双音频播放、切轨、暂停、自动播放拦截、接管及画面提前结束。真实雷鸟电视的卡顿改善程度仍需安装后确认，平板流畅并不能单独排除电视解码能力或网络差异。
