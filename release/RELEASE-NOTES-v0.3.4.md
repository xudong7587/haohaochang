# 好好唱 v0.3.4

修复资源版本重复占用空间，恢复已有标准曲库整理，并让 PC 承担 AV1、HEVC 等画面的转码。

- 未变化的画面和音轨共用磁盘数据；自动回收超过 10 分钟且没有播放或整理任务引用的旧版本，包括升级前产生的副本。保留原始来源、当前可用资源和仍被引用的文件。
- “曲库管理 → 标准曲库 → 整理已有标准曲库”可批量迁移旧格式并清理过期版本。已合格歌曲不重新去人声，逐首显示提交结果。
- 新版 PC 优先使用 NVIDIA 解码、CUDA 缩放和 NVENC 编码转换画面，失败时在 PC 使用 CPU 后备。NAS 保留传输、完整性校验和发布职责。
- 去掉资源生成后的重复完整解码校验；修复 Windows 任务状态读写冲突，区分 PC 转换画面和 NAS 准备音轨阶段。

请同时升级 NAS 镜像和 PC 整理器。PC 先停止旧服务，再覆盖程序并启动，保留 worker.json、运行环境和 data。NAS 升级保留原来的数据／媒体／下载目录映射。旧版本回收在启动后及每 15 分钟安排，正在使用的歌曲会延后处理。

本地通过 92 项 Node 测试、15 项 Python 协议／并发测试、生产构建与相关浏览器验证。真实 GPU 路径已验证；家庭 NAS 与 RTX 4070 SUPER 的完整入库速度仍以升级后实测为准。
