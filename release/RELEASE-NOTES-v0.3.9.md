# 好好唱 v0.3.9

本版将曲库和任务页面改为可分页、可收起的工作台，加入歌曲封面、歌手海报墙和独立原唱试听。

- 只保留一个歌房和一个点歌队列。TV 优先；同类新播放页面接管后，旧页面停止出声，仍可点歌和控制。等待中的网页可在 TV 离线后接续，已被接管的旧页面不会自动抢回。
- 新歌整理完成后自动获取封面；已有曲库在启动时和每分钟分批补齐，每批最多 4 个在途封面任务，低于点歌和整理任务优先级。已有规范封面跳过，没有匹配结果或失败时至少隔 24 小时再试。B站歌曲优先原视频封面，其他歌曲匹配专辑；仍可手动重新获取。
- 曲库支持歌手分组、跨页选择和编辑弹窗；后台、NAS PC 页和 Windows PC 整理器统一任务分组、分页、进度与详情。
- 歌手墙可试听原唱、拖动进度、查看歌曲目录；手机、网页歌房和 TV 共用歌曲封面。管理页显示版本号和 GitHub 链接，更新网页图标。

升级 NAS 后刷新网页或重新打开 TV 页面即可使用。Windows PC 整理器需要更新程序包才能看到新版任务界面：先停止旧程序，保留 worker.json、runtime 和 data，再覆盖程序文件。APK 提供 v0.3.9 debug 测试包。

本地 117 项 Node 测试及生产构建通过，包含真实 FFmpeg 媒体测试。浏览器验证覆盖封面预览、曲库与任务页面、TV 扫码，以及多页面接管、旧页面静音、断线回退和延迟响应。真实手机、电视遥控器及家庭 PC 新界面仍需实机验收；本轮没有改写生产 NAS。
