# 好好唱 v0.4.2 · 曲库操作优化

已使用 v0.4.0 或 v0.4.1 的用户，本次只需更新 NAS，再刷新管理页；TV 点“热更新网页”。TV APK 和 PC 整理器可继续使用，无需重新处理歌曲。

- 曲库排序改为歌名、歌手、时间按钮，重复点击切换升降序，当前排序紫色高亮并自动记住。
- 全选、本页和筛选结果横排显示；新增缺少歌词、封面、视频和视频分辨率筛选。多个筛选条件同时满足，修改筛选后清空勾选。
- 歌手照片在展示时检测并裁掉对称的上下黑边，再铺满照片区域；保留原图，无法可靠判断时不裁切。
- 在线找歌预览的关闭按钮固定在卡片右上角，内容滚动到底部也可关闭。
- 明确 LRC 编辑入口：选择候选或导入文件后可修改署名、文字和时间戳，保存后生效。

“来源音频-*.mka”是无损保留的原始音轨，数据库仍引用它，不能直接手工删除。本次没有删除来源音频，也没有改写用户曲库。

附件统一为 `haohaochang-nas-v0.4.2.zip`、`haohaochang-tv-v0.4.2.apk`、`haohaochang-resource-ai-v0.4.2.zip`、`haohaochang-preprocess-v0.4.2.zip` 和 `SHA256SUMS-v0.4.2.txt`。客户端附件供新安装或可选更新，TV 原生播放与 PC 处理逻辑保持不变。

本地 161 项 Node 测试、生产构建、曲库及在线播放器浏览器回归通过。家庭 NAS、TV 与真实 B站图片仍需升级后验收；发布构建和镜像状态见 [Actions](https://github.com/xudong7587/haohaochang/actions)。
