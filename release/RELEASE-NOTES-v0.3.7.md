- 普通整理直接保留原画面编码、分辨率和帧率，取消自动视频转码。修复源音视频尾部时长不同导致的失败；显式兼容转换显示实际进度，并核对 PC 完整校验后的文件。

- 预览弹窗移除二维码和登录检测，首页及设置继续提供登录。增加 WBI 签名接口与备用视频线路重试，避免把取流失败一律归因未登录；重试保留试听位置。

本地 111 项 Node 测试、16 项 Python 协议测试通过，点歌、播放、曲库、PC 状态和在线预览浏览器检查通过。真实 4K AV1/HEVC 封装前后视频码流一致；用户提供的 B站链接在本机实际播放 1080p 视频与音频成功。NAS 吞吐量和电视原编码兼容仍需部署后验收。
