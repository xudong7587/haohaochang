# v1.0.6 · 手机点歌、独立歌房与 NAS 裁剪

## 这次更新

- 同一 APK 适配电视和 Android 手机。手机横竖屏压缩导航、标题及控制栏，优先显示歌曲卡片；保留深紫色，增加轻渐变、细描边和阴影。
- 网页歌房与 TV 布局对齐，网页和 APK 在线找歌均可显示 NAS 缓存的视频封面。
- 默认仍直接进入共享家庭歌房。需要分开唱时，可从网页“独立歌房”或 APK 设置进入，创建房间或用 6 位号码加入。各房间独立保存队列、播放控制和歌词微调，歌曲资源共享；同房加入可以接管播放，不提供同步多端出声。
- PC 未配置、离线、拒绝任务或处理失败时，NAS 使用 FFmpeg CPU 接续裁剪。保留分辨率与帧率，HDR 裁剪明确转为 SDR；完整校验后保存，支持中断重试与取消清理。
- 旧版仅因 PC 离线而等待的在线下载会在重启后自动继续。伴奏分离仍通过已配置的 PC、NAS 分离容器／NPU或外部 API 完成；NPU 不负责视频裁剪。

## 更新顺序

1. 拉取 `ghcr.io/xudong7587/haohaochang:v1.0.6`（或更新后的 `latest`），重建原 NAS 主容器。保留 `/data`、`/media`、`/download`、密码和已有分离服务配置。
2. 覆盖安装 `haohaochang-tv-v1.0.6.apk`，正式签名保持一致。手机和 TV 使用同一安装包。
3. 现有 PC／NPU 协议兼容，可继续使用。新装 PC 用 `haohaochang-resource-ai-v1.0.6.zip`；覆盖更新前退出整理器，保留配置、运行环境、模型及数据。
4. 新部署使用 `haohaochang-nas-v1.0.6.zip` 中对应 Compose；独立重命名工具为 `haohaochang-preprocess-v1.0.6.zip`。文件校验见 `SHA256SUMS-v1.0.6.txt`。

## 验证范围

本地 Node 217 项（216 通过、1 项 Linux 专属跳过），Android 38 项单测、lint 与 APK 构建通过；网页横竖屏、独立歌房与在线找歌回归通过。裁剪测试使用真实 FFmpeg，覆盖多音轨、独立画面、片尾、HDR、缓存变化、PC 离线／忙碌及升级恢复。

本轮手机新版 USB 复测因设备断开未完成，未测真实 NAS CPU 裁剪耗时或多房间实机并发。安装后的遥控、扫码、解码及家庭网络体验请按包内检查说明核对。
