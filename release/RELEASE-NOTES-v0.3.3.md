本版修复批量整理后在线任务被阻塞、任务数量可见但歌曲和进度不清楚的问题，并重新整理设置与曲库界面。

- PC GPU 默认同时处理 3 首，CPU 默认 1 首；支持在 worker.json 设置 concurrency（1–3）。NAS 同时派发 3 项常规工作，为在线任务预留额外调度位置；在线后续导入继承优先级，PC 执行池仍最多 3 首。
- 在线搜索升级后默认开启，保留 Cookie；此后手动关闭的设置会保留。在线队列独立接纳最多 200 个在途任务，不再被本地整理数量阻塞。
- 后台与 PC 页面显示歌曲、歌手、阶段、耗时及模型当前步骤百分比；全部在途任务保留展示，避免被近期已结束任务挤出列表。
- 设置分为后台任务、媒体与导入、在线资源、资料与歌词、播放画面和连接地址；切换板块保留草稿。
- 删除旧曲库工具入口；“全部整理”移入待整理和半标准分类，只处理当前分类。标准曲库按歌手折叠，限制展开区域高度。
- 预处理工具新增选中项批量文字替换、删除《》和撤销；先修改预览，最终重命名仍检查重名、备份 NFO，并在失败时回滚。

升级时请同时更新 NAS 和 PC 整理器。NAS 保留密码、端口和目录映射，重新拉取镜像并创建容器；镜像提供 v0.3.3 与 latest 标签，架构为 linux/amd64。PC 先停止旧服务，再覆盖新版程序，保留 worker.json、runtime、.venv 和 data，随后重新启动 start.cmd。旧 PC 进程不会因为文件已覆盖就自动变为三路并发。电视网页会随 NAS 更新，已有 APK 通常无需重装。

附件包含 NAS 安装包、PC 整理器、预处理工具、两种独立 Compose、配套 debug APK 和 SHA256SUMS.txt。预处理工具解压到媒体目录，使用“好好唱重命名.cmd”启动。

本地 85 项后端测试、12 项 Python 协议／并发测试、五类浏览器检查和 Windows 启动检查通过。本机 RTX 5080 Laptop GPU 使用三个独立的 12 秒合成音频完成真实三路分离，约 11 秒全部结束并通过输出校验；真实歌曲音质和家庭 NAS／电视／音响由用户部署后验收。
