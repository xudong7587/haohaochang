# 好好唱 v0.4.1 · 曲库管理修复

**已使用 v0.4.0 TV 和 PC 的用户，本次只需更新 NAS。** 更新后刷新管理页；TV 可点“热更新网页”。无需重新安装 TV APK 或 PC 整理器，也无需重新下载、转换现有歌曲。

- “已隐藏”歌曲旁增加“彻底删除”。查看文件清单并确认后，删除歌曲记录及列出的媒体；取消或失败时保留歌曲。
- 曲库支持按歌手、歌名、加入时间正序／倒序排列，浏览器记住选择。先排序再分页；按歌手分组时，组内使用所选排序。
- 所有歌曲行显示实际视频分辨率，包括 480p、720p。旧资源缺少尺寸时自动补读媒体头并缓存，不重新编码；无视频或暂时无法读取的歌曲明确标注。

全套附件仍提供统一版本号，供新安装或希望统一版本的用户使用：`haohaochang-nas-v0.4.1.zip`、`haohaochang-tv-v0.4.1.apk`、`haohaochang-resource-ai-v0.4.1.zip`、`haohaochang-preprocess-v0.4.1.zip`、`SHA256SUMS-v0.4.1.txt`。TV 原生播放和 PC 处理逻辑与 v0.4.0 相同，升级这些客户端是可选的。

若仍使用 v0.3.x，要启用 v0.4.0 引入的原生播放与新版 PC 处理能力，请手动安装本页最新客户端；旧版更新器不识别版本化附件。

本地 159 项 Node 测试、生产构建和曲库浏览器回归通过；另在运行中的隔离预览验证了删除清单、取消、确认后记录与目录删除以及其他歌曲保留。未访问或修改生产曲库。发布构建和镜像状态见 [Actions](https://github.com/xudong7587/haohaochang/actions)。
