# 好好唱 · 家庭 KTV

把想唱的歌留在家里的 NAS，电视或浏览器负责播放，手机扫码点歌。所有设备共用歌房和已点列表。

[下载稳定版](https://github.com/xudong7587/haohaochang/releases/latest) · [使用手册](docs/USER-GUIDE.md) · [Changelog](CHANGELOG.md) · [NPU 测试版说明](docs/NPU-RC1.md)

好好唱提供曲库整理、在线找歌、原唱与伴奏切换、歌词显示和多人点歌。TV 界面与播放全部原生，遥控器可以完成点歌、切歌和歌词调整；网页歌房也能直接播放。

## 我需要准备什么？

- **能运行 Docker 的 NAS**：保存歌曲、设置和已点列表，曲库目录需要读写权限。
- **一台播放设备**：Android 电视安装 TV 应用，或在电脑浏览器打开网页歌房。手机扫码即可点歌。
- **麦克风和音响**：连接电视的音响或混音设备。好好唱负责播放音乐，没有手机录音、麦克风返听或唱歌评分。
- **Windows 电脑，可选**：只有普通 MV 时，用它生成伴奏；已有原唱、伴奏双音轨的歌曲可直接整理。也能配置兼容的分离 API 作为后备。

所有设备共用一个歌房、一个已点列表。TV 优先播放；新开的 TV 可以接管旧 TV，网页歌房不会抢走正在播放的 TV。

## 先把第一首歌唱起来

### 1. 在 NAS 安装

从 Release 下载 `haohaochang-nas-v0.4.6.zip`，解压后导入其中一份 Compose 配置。

| 使用方式 | 配置文件 |
| --- | --- |
| Linux NAS，希望电视和 PC 自动连接家庭歌房 | `docker-compose.lan.yaml`，单独使用 host 网络配置 |
| 普通 Docker 部署，或手动填写 PC 地址 | `docker-compose.yaml` |

修改管理密码和三个目录映射：`/data` 保存设置、数据库与任务；`/media` 保存正式曲库；`/download` 暂存下载。管理密码至少 12 位。LAN 配置默认端口为 **43210**，普通配置默认为 **3210**。

镜像是 `ghcr.io/xudong7587/haohaochang:latest`，可以公开拉取。启动后打开 `http://NAS-IP:端口/admin`，输入管理密码。完整安装与迁移步骤见[手册](docs/USER-GUIDE.md#1-安装-nas)。

### 2. 准备歌曲

已有文件就放入映射的曲库目录，在后台扫描；想从网上找，就打开“在线找歌”搜索 B 站视频，试听、选取片段后加入曲库。也可以粘贴链接，或导入 B 站收藏夹。

人工选定的视频不会因画面、原唱与标注时长不同而被拒绝。下载失败会尝试备用线路；仍失败时，可在 PC 整理器页或任务列表点击“重试”。“删除”只移除失败任务记录，保留歌曲和媒体。

普通 MV 需要生成伴奏时，下载 `haohaochang-resource-ai-v0.4.6.zip`，在 Windows 解压并运行 `start.cmd`。首次会下载运行环境；启动成功后显示整理器窗口，NAS 连接它处理裁剪和分离任务。

曲库分为待整理、半标准、标准三类。**半标准歌曲已有原唱和伴奏，也能唱；歌词缺失不会把已经可唱的歌曲挡在队列外。** 标准歌曲还具备视频画面。需要核对的信息会留在编辑器或任务列表中。

### 3. 打开播放设备，手机扫码

电视从 Release 下载安装 `haohaochang-tv-v0.4.6.apk`（不通过应用商店分发），首次启动自动寻找同一局域网的 NAS，找到后显示二维码；找不到可手动输入地址，再按提示用手机扫码登录。没有电视时，在后台打开“网页歌房” `/play`。

手机扫描歌房二维码，按歌名或歌手点歌，也能暂停、切歌、切换原唱／伴奏和发送掌声。无人点歌时随机播放原唱，已点歌曲就绪后接管播放。

## 平时怎么用？

- **手机没搜到歌**：进入“在线找歌”，优先选 B 站视频；没有合适画面可点“先找音频 + 歌词”。手机任务优先于后台找歌排队，完成后自动加入已点列表。画面下载失败会尝试音频方案；找不到可靠歌词或资源时仍需要核对。
- **管理曲库**：默认直接展开歌曲，可以切换行列表和海报墙。封面优先使用歌曲或专辑图片，没有时尝试歌手照片。筛选、分页、批量整理和编辑在两种视图中一致。支持歌手／歌名／加入时间正倒序、所有视频的实际分辨率标注，以及已隐藏歌曲旁的“彻底删除”按钮。
- **修改一首歌**：点击“编辑歌曲”，在同一窗口调整资料、视频、歌词和维护操作。结果与错误会在窗口内显示，未保存的草稿会保留。
- **更换封面**：编辑器显示当前封面；可以搜索 B站视频封面，也能上传 JPG、PNG 或 WebP。已有封面同样能换，图片自动居中裁为方形，预览满意后点击“保存封面”。此操作由 NAS 完成，不需要 PC。
- **歌星资料**：后台“歌星管理”可编辑照片和介绍，详情页显示大图与歌曲瀑布流；网页歌房“歌星点歌”使用相同资料，点击歌曲即可点歌。
- **手机直接播放**：浏览器打开 `/play` 可本机播放，`/mobile` 只负责点歌；TV APK 使用原生横屏界面。
- **遥控器操作**：卡片上下左右移动并自动滚动。内容首列左键进入字母区，再向左返回侧栏；末行下键进入底栏。全屏返回／下键打开控制，再按返回收起，选择“退出全屏”才返回点歌页。
- **查找歌词**：支持 QQ 音乐、网易云音乐和 LRCLIB，可自动选择来源或手动指定。多份歌词会显示歌手、版本和时长，预览后选择，再保存到歌曲。
- **MV 已有字幕**：在网页歌房或 TV 点“隐藏歌词”，关掉系统滚动歌词和时间微调控件；视频自身的字幕保留。选择会记在当前浏览器或 TV 内。
- **查看 PC 工作情况**：整理器窗口、右下角托盘和 NAS 的 `/pc` 页面都能查看任务。窗口显示 GPU、显存、CPU 和内存占用；关闭窗口继续后台运行，通过“退出整理器”结束空闲服务。

编辑歌曲的“视频画面”可从保存的 B站来源更新，也可按歌名、歌手搜索或粘贴新链接。只有同一链接、同一分 P 且前后都确认未裁剪，才保留原唱和伴奏；其他更新会重新提取原唱、分离伴奏并匹配歌词，整套验证成功后替换。失败时旧资源仍可用。

视频默认保留原编码、分辨率与帧率，不统一降到 1080p 或 30fps。电视遇到不兼容画面时，可手动进行 PC 兼容转换：自动尝试 NVENC、Quick Sync、AMF，失败回退 CPU，保持原尺寸与帧率。歌词微调按歌曲保存在 NAS，下次播放继续使用。

## 想在 NAS 上用 NPU 分离伴奏？

**v0.4.6.rc1 仅为 Docker NPU 测试版本，稳定版仍是 v0.4.6。** 不发布 RC1 TV 或 PC 安装包，也不更新 Docker 的 `latest`。

RC1 自动检测 Intel NPU，匹配内置 htdemucs 并完成编译、试运行。分离依次尝试 **PC 连接器 → NAS NPU → 外部 API**；前一服务不可用或失败才转后备。它不是所有厂商 NPU 的通用版本：目前仅 Intel OpenVINO 路线，其他 Intel 设备也需通过检测，AMD／高通尚未适配。

需要明确拉取这两个版本，不能使用 `latest`：

```sh
docker pull ghcr.io/xudong7587/haohaochang:0.4.6.rc1
docker pull ghcr.io/xudong7587/haohaochang-separator-npu:0.4.6.rc1
```

设备映射、LAN／桥接配置、测试边界和回退方法见 [RC1 安装说明](docs/NPU-RC1.md)。首次模型编译可能需要数分钟；后续使用持久缓存。NPU 只接管伴奏分离，原有 PC 视频裁剪流程保留。

## 怎么更新？

v0.4.6 暂停应用内更新，隐藏 TV、PC 和网页热更新按钮。

| 要更新的部分 | 操作 |
| --- | --- |
| NAS | Docker 拉取新镜像并重建，保留挂载目录、密码和端口 |
| TV | 下载 Release APK 后覆盖安装，沿用原签名与登录 |
| PC 整理器 | 等待任务完成，退出整理器，解压新版 ZIP 覆盖后运行 `start.cmd` |

PC 覆盖时保留 `worker.json`、`runtime`、`.venv` 和 `data`。关闭窗口只是隐藏到托盘，请使用“退出整理器”。

## 先了解这些边界

外部下载源和歌词库可能暂时不可用；“没找到”不一定是歌名填错。手动查找 LRC 会展示时长或演唱者不同的同名候选并提示核对，不直接替换当前歌词；自动整理仍检查歌名、演唱者和时长。AI 分离效果随录音而变，不能保证每首歌的人声都完全消失。

本版包含本地自动化验证；实际电视安装、遥控器、解码能力以及家庭网络连接仍需在自己的设备上确认。公司环境的开发测试只使用 localhost，未自动部署到真实 NAS。

遇到问题先看[排错与常见问题](docs/USER-GUIDE.md#10-常见问题)，再查看 NAS 的任务详情或导出诊断日志。
