# 好好唱 · 家庭 KTV

把歌曲放在 NAS，用电视或电脑播放，手机扫码点歌。第一次准备好的资源会长期留在正式曲库，下次直接唱。

本地本轮功能与待验收项见 [开发状态](docs/PROJECT-STATUS.md)，尚未发布。

## 从哪里开始

[下载最新版本](https://github.com/xudong7587/haohaochang/releases/latest) · [使用手册](docs/USER-GUIDE.md)

| 你要做什么 | 下载 / 打开 |
| --- | --- |
| 在 NAS 部署 | `docker-compose.yaml` |
| 在电视唱歌 | `haohaochang-tv-0.2.0-debug.apk` |
| 在电脑浏览器唱歌 | NAS 后台点击“打开网页歌房” |
| 用手机点歌和互动 | 扫描播放画面的二维码，无需安装或输入密码 |
| 用 PC 生成人声分离伴奏 | `haohaochang-resource-ai.zip`，解压运行 `start.cmd` |

## NAS 安装

在 UGOS 等 NAS 的 Docker 中创建 Compose 项目，导入下载的 `docker-compose.yaml`，只修改：

- 管理密码 `ADMIN_PASSWORD`。
- 左侧访问端口，例如 `43210:3210`。
- 三个目录映射：`/data` 保存设置，`/media` 保存正式曲库，`/download` 接收下载。

镜像为 `ghcr.io/xudong7587/haohaochang:latest`，公开拉取，无需登录或创建 `.env`。曲库必须可写。

启动后打开 `http://NAS-IP:端口/admin`，输入管理密码。其余设置都在网页完成，自动保存在持久化目录。

## 开始唱歌

1. 在后台扫描曲库，检查歌手、歌名和音轨，准备播放版本。
2. TV APK 填 NAS 地址并登录；没有电视就在后台打开网页歌房。
3. 手机扫码点歌。全屏二维码常驻角落，已点列表间隔出现。

无人点歌时随机播放原唱，点歌后使用可用伴奏。普通 MV 需要分离才能提供伴奏；纯伴奏文件没有原唱。

## 自动整理与 PC 算力

后台可以监控 B 站收藏夹，下载到 `/download`，按歌手、歌名整理入库；也可以直接提出自动找歌请求。信息或资源不确定时进入待处理。

好好唱资源 AI 整理器会检测 PC 显卡，选择兼容环境，显示模型、任务和资源占用。PC 优先处理分离，忙碌或离线时可使用配置的兼容 API。信息识别 API 与音频分离 API 是两套设置。

新格式纯音频使用浏览器实时频谱和底部同步歌词，图片轮播仍待补齐。原文件、原唱、伴奏与处理后的版本都保存到正式曲库，不会自动过期。找到的 MTV 候选先保存，确认版本后可替换。
