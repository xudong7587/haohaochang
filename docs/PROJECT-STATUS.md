# 开发状态 · v0.3.0

更新于 2026-09-09。v0.3.0 已完成本地实现、标签 CI、两套镜像启动验证与 latest 更新；发布入口为 [v0.3.0](https://github.com/xudong7587/haohaochang/releases/tag/v0.3.0)。尚未在家庭 NAS、电视和音响实机验收。此前 v0.2.0 的发布记录保留在验证文档。

## 本轮新增

- NAS 自动发现局域网 PC、一次性配对、实际内网地址显示；新增独立 Docker LAN host 网络配置。PC 默认 LAN 监听，KTV_LOCAL_ONLY=1 用于公司本机测试。
- 在线找歌采用歌名/歌手输入与 B站视频瀑布流，歌词来源的录音时长用于排序；纯流预览支持播放、暂停、区间标记和入库。
- PC 共用队列执行准确 H.264/AAC 裁剪与伴奏分离，NAS 保留原始下载、任务检查点和待核对信息，离线任务等待 PC 恢复。
- 播放端每歌歌词微调，左右键每次 0.1 秒，第一句前圆点倒数与滚动切换，支持减少动态效果设置。
- 本地 76 项 Node 测试、11 项 Python 工作协议测试、2 项模拟 LAN 测试通过；四类浏览器回归通过。真实 B站搜索和独立音视频 Range 代理请求通过；真实 FFmpeg 裁剪验证通过。没有探测公司局域网、修改防火墙或向真实曲库添加样例。

更新于 2026-09-09。第 0 批公共契约和第 1 批 T1–T8 已全部集成，已完成标签 CI 和镜像构建、启动验证。最终发布入口为 [v0.2.0](https://github.com/xudong7587/haohaochang/releases/tag/v0.2.0)；发布结果以该页面和对应 Actions 为准。

## 已完成

- 后端拆分为路由、歌房状态、调度器、任务处理器、候选提供方、资源服务和分离协议；前端启动、工作台、资料编辑、播放器生命周期分别独立。
- 资料和资源使用不同修订号。资料提交须带 expectedRevision；同歌任务串行，异歌最多并行两项。阶段检查点支持失败和进程重启后的幂等重试。
- 新格式资源在独立目录完成复制、完整解码与时长验证后一次发布。失效文件会降级，失败保留上一个版本。旧格式继续兼容。
- 补画面保留原唱、伴奏和歌词，需要核对录音版本及起始偏移。新视频不能仅凭时长接近就自动替换已有音源。
- 链接解析、下载和导入共用 SourceCandidate，保留分 P、标题、识别证据。视频核对区提供确认、拒绝、重新搜索三个动作。
- 编辑草稿在刷新和切换分类时保留；检测到后台更新时明确提示冲突。批量更新逐首显示成功、冲突、待核对或失败。已隐藏歌曲不能点播，可在后台恢复。
- 歌词保存统一更新数据库与 LRC 文件。支持可配置的本地中文／增强 LRC 索引，优先核对歌名、歌手、录音版本和时长，LRCLIB 作为后备，保留来源、哈希及毫秒偏移。
- 播放器覆盖单路和双路音频失败、声音授权重试、暂停、切歌、租约丢失和恢复。画面提前结束不提前切歌。纯音频支持频谱、共享图片轮播及安全的图片设置。
- NAS 记录远端任务 ID，重启后继续查询；上传重试复用幂等键。PC 忙碌或离线按配置转后备服务。PC 服务拆分持久任务、推理和上传容量管理，重启后将中断推理标为失败以便重试。

## 验证边界

本地 69 项 Node 测试通过，包含真实 FFmpeg；工作台 11 项端到端检查、管理组件契约测试和播放器异常浏览器测试通过，无页面脚本错误。Python 协议测试使用隔离依赖和模拟推理，不代表本次完整 GPU 音质验收。CI 负责 Linux 浏览器、Docker、Python 和新版 APK 构建，详见 [验证记录](VALIDATION.md)。

本轮只测试 localhost，未探测公司局域网或修改防火墙，未向实际曲库添加测试歌曲。此前用户要求清除的示例保持清除；另一任务修复的真实歌曲与音频备份已保留，见 [伊斯坦堡修复记录](ISTANBUL-REPAIR.md)。本机预览入口为 http://127.0.0.1:3210/admin。

仍需 NAS／手机／电视 WebView 与音响实机验证、长期播放和大曲库压力测试。未重新完成真实音乐的 GPU 分离音质、付费 API 或外部平台下载全链路验收。历史 CUDA 合成样本验证记录不等于本版本实机通过。

## 后续范围

尚无完整中文歌曲歌词数据库、QQ／网易云／酷狗直接歌词接口、自动声音指纹或强制对齐、重复歌曲自动合并、字体文件上传、B 站凭证自动刷新。可手动导入 LRC 和更多歌曲目录；本地歌词索引配置见 [开发说明](DEVELOPMENT.md)。缺歌词或无法确认录音版本时留在待整理是预期行为。

NAS 保存正式数据，PC／云端只返回分离结果，播放端消费状态。模块负责人和后续任务约定见 [开发分工](DEVELOPMENT-PLAN.md)。
