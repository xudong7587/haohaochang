# TV 0.4.4.2 · 原版视觉与遥控导航修复

本次为现有 v0.4.4 Release 内的第二个 TV APK 补丁，versionCode 24。NAS、PC、Docker 不发布更新；基于 0.4.4.1 的原生实现继续修正，保留 Media3 播放核心。

## 界面与操作

- 底栏参考手机端的小图标设计，不常驻显示按钮名称；播放键保留紫色圆形，其余图标为透明底。遥控焦点落到图标或微调数字时，显示简短功能提示，1.6 秒后自动消失。普通底栏高度缩至 72 dp，全屏保留两层控制空间。

- 对照原版 TV 截图恢复深紫背景、品牌标志、客厅状态卡、图标菜单、浅紫选中态、圆形播放键、封面和歌手头像层次。控件使用原生 View 与矢量绘图，不使用 WebView。
- 不恢复右上角小预览窗口。普通模式视频仍铺满侧栏右侧和底栏上方；点歌面板只使用主区域约 78% 的宽度，右侧约 22% 不遮挡视频。面板为半透明底色，卡片保持紧凑。
- 有点歌播放队列，队列空时继续 NAS 随机播放；普通模式不显示歌词。全屏隐藏侧栏和点歌内容，复用同一组原唱／伴奏、播放／暂停、切歌控件。
- 全屏左端歌词开关、右端退出。微调仅在歌词开启时显示：左侧 `10  3  0.5` 延后，右侧 `0.5  3  10` 提前。取消 0.1 秒档，普通状态显示数字与下方的小箭头；遥控聚焦时显示清晰轮廓。画面聚焦时左右键也按 0.5 秒调整，已有歌曲偏移不清零。
- 遥控上下选择侧栏菜单，确认打开页面，右键进入内容区；卡片上下左右移动并自动滚动，首列左键回侧栏，末行下键到底部控制。底部左右选择按钮，上键返回内容；确认键只执行一次，长按不重复点歌或暂停。
- 主界面初始化落在当前菜单，方向键显式切换焦点区域。进入卡片时调用 Android 的 `requestFocusFromTouch` 离开触控模式，避免“已聚焦但 GridView 选中项仍为空”。返回键保留全屏控制栏唤出／收起逻辑，选择退出全屏回到先前页面。

## 升级

下载 `haohaochang-tv-v0.4.4.2.apk`，使用原签名覆盖安装。0.4.4.1 用户保留原生登录与 NAS 地址；0.4.4 及更早的 WebView 版本首次升级需重新扫码一次。0.4.4.1 更新器支持同一 Release 内补丁，可在设置检查；更旧版本请手动下载。
