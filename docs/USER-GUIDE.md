# 好好唱使用手册

v0.3.4 的功能与验证范围见 [开发状态](PROJECT-STATUS.md)。正式安装先装 NAS，再连接播放设备和手机，最后启用自动下载与 PC 算力。[所有安装文件在 Latest Release](https://github.com/xudong7587/haohaochang/releases/latest)。

## 已有标准曲库整理与空间回收

在“曲库管理 → 标准曲库”点击“整理已有标准曲库”，可把旧播放格式整理为一份画面、独立原唱与伴奏。已经符合新格式的歌曲只检查资源和回收过期版本，不会重新去人声；播放中、播放队列内和已有整理任务的歌曲会跳过，逐首显示提交结果。

“资源版本”用于处理失败时保护此前可用的文件。v0.3.4 起，未改变的画面和音轨共用磁盘数据；不支持硬链接的磁盘会临时复制。NAS 启动后及每 15 分钟安排回收：当前资源通过检查、无播放或整理任务引用、且超过 10 分钟宽限期的旧版本会被移除，包括升级前产生的版本。旧格式生成的缓存视频也会在新格式可用后回收。原始来源和仍有引用的文件保留，请勿手动删除当前版本目录。

需要转换的 AV1、HEVC 等画面可交给新版 PC 整理器。NVIDIA 设备优先硬件解码、缩放和编码为最高 1080p 的 H.264；硬件路径不可用时在 PC 使用 CPU 后备。NAS 仍负责传输、完整性校验和正式入库。请同时更新 NAS 与 PC；旧 PC 不支持此能力时保持原有 NAS 转码流程。

## 1. 安装 NAS

导入 `docker-compose.yaml`，只修改密码、端口和三个目录。

| 配置 | 说明 |
| --- | --- |
| `ADMIN_PASSWORD` | 至少 12 位管理密码 |
| `43210:3210` | 左侧是自己的 NAS 端口，右侧固定 3210 |
| NAS 设置目录 → `/data` | 设置、数据库、任务记录；必须持久化 |
| NAS 曲库目录 → `/media` | 正式媒体库，需要读写权限 |
| NAS 下载目录 → `/download` | 下载入口，与正式曲库分开 |

镜像 `ghcr.io/xudong7587/haohaochang:latest` 公开拉取。无需登录、无需 `.env`，也无需自己创建设置文件。

启动后打开 `http://NAS-IP:端口/admin`。用管理密码登录，其余设置保存在后台。普通部署只用主 Compose；`docker-compose.ai.yaml` 是可选 NAS CPU 分离容器，使用 PC 或 API 时不用装。

需要局域网 PC 自动连接时，Linux NAS 请单独使用安装包中的 **docker-compose.lan.yaml**：保留原有三个目录映射和管理密码，按需修改 PORT（示例为 43210），运行 `docker compose -f docker-compose.lan.yaml up -d`。从桥接配置迁移时先停止旧 ktv 容器，避免两个进程同时写同一个数据库；保留数据目录。LAN 配置使用 host 网络，不填写 ports 或自定义容器子网，也不叠加主 Compose。普通桥接配置仍可手动连接 PC，但广播自动发现不能保证穿过 Docker 桥接网络。

旧部署增加 `/download`，移除曲库映射末尾的 `:ro`，保留旧密码、端口和数据目录。更新时在 UGOS 重新拉取并重建，或运行：

```sh
docker compose pull
docker compose up -d
```

## 2. 整理已有歌曲

1. 曲库工作台顶部粘贴链接，点击“解析 MV 链接”，核对结果后下载；已有文件可通过设置页扫描曲库。
2. 使用“刷新曲库元数据”批量更新可靠匹配的歌名、歌手，或点击歌曲行的“刷新歌名 / 歌手”查看单首结果。
3. 点击“自动找歌词”或导入 LRC，使用“解析 / 补充 MV”填写视频链接。
4. 保存并继续整理，后台任务显示处理结果。音轨序号、左右声道等设置在“音轨高级设置”。

待整理区接收原始媒体、资料待核对或尚未生成双音轨的歌曲；半标准区已有原唱和伴奏，标准区还有视频。歌词可选，不影响整理和分类。空曲库不会自动生成示例歌曲。排队、处理中和待核对的下载文件都会显示，避免误以为未识别。

歌名、歌手已确认时点击“开始整理”即可继续，先自动查找歌词，找不到也继续制作音轨。多个歌名、歌手、版本和时长均匹配的歌词候选，默认选择时长最接近的一份；仍可在编辑歌曲中试听、调整或导入自己的 LRC。“全部整理”提交待整理歌曲并逐项显示结果，已排队项目跳过，缺歌名或歌手的项目留待补充。

“删除”先列出将永久移除的媒体文件或整首歌曲资源目录，确认后执行。播放队列内或正在处理的歌曲需要先结束任务或移出队列。编辑页的“移出曲库”仍只隐藏歌曲、保留媒体，可恢复。

| 原文件 | 设置与结果 |
| --- | --- |
| 普通 MV / 普通音频 | 原始音频；分离后才能提供伴奏 |
| 纯伴奏 | 不做分离，没有原唱版本 |
| KTV 双音轨 | 指定伴奏和原唱的音轨序号，从 0 开始 |
| KTV 左右声道 | 指定 0 左 / 1 右，先试听确认 |

普通立体声不等于原唱、伴奏各占一个声道。已有文件的“整理”修改资料，不自动重命名或移动原文件。

系统读取同名 NFO、`musicvideo.nfo`、`movie.nfo`；歌手来自明确的 artist 字段，不把 UP 主当歌手。封面可用同名 JPG/PNG、同名 `-poster.jpg`、目录 `cover.jpg` 等。

标签可手动选男声、女声、组合、大陆、港台、欧美、语言、曲风等；AI 可辅助填写，但需要核对不确定信息。

## 3. TV 和网页歌房

电视安装 `haohaochang-tv-0.2.0-debug.apk`，填写 NAS 根地址并登录。遥控器菜单键修改地址，方向键选择，确定键操作，返回键关闭弹层或返回点歌页。

没有电视时，在管理后台点击“打开网页歌房”，独立打开 `/play`。同一浏览器可以复用登录后的客厅凭证；新设备由主人首次登录一次。浏览器首次可能需要点击“开始播放”以允许声音。

无人点歌时随机播放原唱；点歌准备好后接管播放，队列结束后恢复随机播放。默认使用已有伴奏，普通 MV 未分离时只能播放原唱。

全屏二维码固定在右上角。已点列表每 30 秒出现约 6 秒，显示当前与接下来 3 首，空队列不显示。

所有终端共用一个歌房，只允许一台活跃播放器。切换电视/网页播放时，关闭原播放页，另一台会自动重连。

## 4. 手机扫码点歌与互动

扫描播放画面中的二维码即可加入，无需安装 APK，也不用输入网址和密码。手机需能访问二维码指向的 NAS 地址。

手机可按歌名、歌手和标签找歌，调整待唱队列，暂停、切歌、切换原唱/伴奏，并发送掌声、礼花、爱心和星星。置顶不会打断当前歌曲。

二维码包含客厅凭证，只分享给一起唱歌的人。手机不负责录音或麦克风返听；麦克风连接实际音响/混音设备。

## 5. 好好唱资源 AI 整理器（PC）

下载 `haohaochang-resource-ai.zip`，在 Windows 10/11 x64 解压并运行 `start.cmd`，之后安装与任务处理都在后台进行，不会自动打开浏览器或保留命令行窗口。第一次需要下载 Python、PyTorch 和模型；网络失败可重新启动。以后复用环境。

程序先检测显卡和驱动，选择运行环境。兼容 NVIDIA GPU 使用 CUDA，小显存使用短分段；没有支持的显卡、驱动不兼容或实际 CUDA 检查失败时回退 CPU。目前不包含 AMD/Intel GPU 加速后端。

在 NAS 内网地址或反代域名后加 `/pc`，用 NAS 管理密码查看状态，例如 `http://NAS-IP:43210/pc`。管理端 AI 设置也有入口；使用已有反代域名即可，无需单独转发 PC 工作端口。首次安装完成前显示等待连接，安装日志在 PC 的 `runtime/launcher.log`。

默认模型为 `htdemucs`；高级用户可在 NAS 比较耗时更长的 `htdemucs_ft`。状态页显示实际任务阶段、日志，以及整机 CPU、内存和 GPU 占用。

默认监听局域网并显示 PC 的实际地址。NAS 后台启用 AI 伴奏分离，保持“自动发现并连接 PC”选中；打开同一家庭局域网中的 PC 整理器后，通常在 15 秒内自动连接，无需填写地址或复制密钥。旧版只监听本机的配置会迁移到 LAN 模式。若存在多个 PC，优先保持已连接且在线的那一台。

局域网发现使用 UDP 43211，PC 工作接口默认 TCP 8000。自动配对只接受内网来源和短时、单次凭据；日常任务仍使用密钥认证。程序不自动修改防火墙；如果 Windows 提示网络访问，请按家庭专用网络的设置处理。电脑与 NAS 处于不同 VLAN、访客网络或 Docker 桥接网络时，发现可能被阻断；后台高级设置仍支持手动填写 PC 的实际局域网 IP。

`127.0.0.1` 永远指向发起连接的设备自身，不能用于 NAS 连接另一台 PC。公司环境本机测试请设置 `KTV_LOCAL_ONLY=1` 后启动整理器，NAS 测试实例不启用发现。

PC 空闲时优先使用；分离可按配置使用兼容的备用 API。裁剪必须由支持新版协议的 PC 执行。PC 未上线或连接中断时任务显示“等待 PC 上线”，发现恢复后继续查询保存的任务；手动连接模式可点击重试。没有完成的片段不会冒充可播放歌曲。

配置在 `worker.json`，环境在 `runtime`，模型和任务在 `data`。重复运行 `start.cmd` 会复用服务，关闭网页不会停止服务。升级前停止旧整理器进程，再覆盖程序文件，保留这些配置和数据。详细说明见 [PC 说明](../pc-worker/README.md)。

## 6. 下载、找歌与信息 AI

在后台启用在线资源和 AI 伴奏分离。“在线找歌”只保留歌名、歌手输入，默认返回 B站视频瀑布流。若歌词来源提供唯一匹配录音的真实时长，优先排列长度接近的视频；没有明确时长时按平台相关度展示，不把最后一句歌词的时间当成歌曲长度。

点击视频卡片打开纯视频流预览，下方有播放、暂停、加入曲库。可以在播放或暂停时点击“标记开头”“标记结束”，精确采用当时的视频时间；只标一端时另一端使用视频起点或结尾，不标记则采用整段，“恢复全部”清除标记。结束必须晚于开头。

**加入曲库 → 等待 PC 就绪 → NAS 下载原视频 → PC 裁剪所选片段 → 核对资料与歌词 → 从片段提取音频 → PC 去除人声 → 入库。**

加入曲库不会自动点唱。处理进度在后台任务中查看，身份信息不确定时进入待核对；缺少歌词不会阻止整理。歌名、歌手采用本次搜索确认的输入，不把 UP 主当成歌手。裁剪前的下载保存在 `/download/.ktv-online/sources`，片段也单独保留；这些中间文件不会被自动扫描为完整歌曲。

在线找歌需要在“设置与任务 → 在线资源”勾选启用在线搜索并保存。Cookie 在“B 站收藏夹自动下载”区域填写，也供在线找歌使用；保存 Cookie 不会自动开启在线搜索，不必为了在线找歌启用收藏夹监控。

预览优先读取 B站播放器接口，必要时回退 yt-dlp，并短时复用解析结果。平台限流、登录要求或地区限制仍可能让预览/下载失败；页面提供重试和原视频入口，按需在后台保存自己的 B站 Cookie。未接入其他平台的视频瀑布流。

B 站收藏夹可以在后台直接监控：填收藏夹链接或 `fid`，不是用户 UID。首次同步包含已有收藏，每轮最多 100 项并继续分页。按需填写自己的 Cookie。也可以让现有 bili-sync 下载到相同 `/download`，同一收藏夹建议只用一个下载入口。

下载目录中的文件稳定约 60 秒后自动整理到“歌手 / 歌手 - 歌名”。源文件保留，信息不确定的先待核对。

“AI 歌曲信息识别与刮削”单独填写支持 Responses 或 Chat Completions JSON 输出的地址、模型和密钥，可选联网查证。它识别歌手、歌名和标签，不做人声分离，也不能凭空保证准确歌词。测试按钮会调用一次真实 API。

## 7. 只有音频时怎么唱

新播放格式使用浏览器实时频谱与共享图片轮播，不额外生成整首背景视频。旧格式已有的背景视频仍可兼容播放。

同名封面用于背景；还可在音频旁建立“文件名.images”目录放 JPG/PNG，最多使用 5 张，约每 12 秒循环切换。没有图片时使用默认背景。此视频不等于真正 MTV，后台仍标记“待补视频”。

歌词放在同名 UTF-8 `.lrc`，或在编辑页粘贴。带时间戳时显示底部当前句/下一句，并按句时间渐进填色；增强 LRC 使用逐字时间，普通 LRC 的着色按句时间估算。没有时间轴则显示普通文本，不伪造同步。

歌词第一句出现前显示传统 KTV 圆点倒数，随后滚动切换当前句与下一句。播放端提供“提前”“延后”和“复位”，每次微调 0.1 秒、最多前后 30 秒，并按歌曲记住。电视舞台和全屏播放时，遥控器左键使歌词提前，右键使歌词延后；输入框和打开的对话框不会触发微调。微调不改动 LRC 原文件或音频，所有连接的播放端共享该歌曲的微调量。

补充 MTV：先放进正式曲库，再在歌曲编辑页关联容器内路径并重新准备。已有源文件和历史播放版本保留。

## 8. 正式文件、备份和维护

`/media` 保存曲库原文件；`/media/好好唱播放资源/歌曲` 按歌手、歌名和 ID 保存新资源，每首有 `画面.mp4`（有视频时）、`原唱.m4a`、`伴奏.m4a`、`歌词.lrc`、`歌曲信息.json`；处理记录与旧资源保留。生成目录不会被扫描为重复歌曲，没有自动过期删除策略。

旧 `/data/cache` 文件在歌曲使用/准备时复制到正式目录，旧文件不自动删除。迁移完成前请一并保留。此目录是历史兼容位置，新产物不再以临时缓存对待。

备份 `/data`、正式曲库及需要保留的 `/download`。停服后备份数据库最简单。原文件、双版本和历史文件都会占空间，当前没有自动容量清理；管理员需关注剩余空间。

## 9. Lucky 反代和常见问题

外部 `https://域名:端口` → Lucky → `http://NAS-IP:宿主机端口`。容器后端使用 HTTP。出现 TLS handshake 错误时，检查后端是否误填 HTTPS。

在 NAS 后台保存完整外部根地址，不附加 `/admin` 或 `/tv`，TV 填相同地址。重新打开播放页后，二维码会使用反代地址。代理应保留认证/Range 请求并允许 `/api/events` 持续输出，证书需被电视信任。

| 问题 | 先检查 |
| --- | --- |
| 扫码打不开 | 手机能否访问 NAS；二维码地址是否更新 |
| 播放失败 | 歌曲是否准备好；当前是否有另一台播放器 |
| 入库失败 | 曲库挂载是否可写；文件是否仍在下载 |
| 分离失败 | PC/API 连通性和整理器任务日志 |
| 下载失败 | NAS 出网、平台限制、Cookie |
| Docker 子网重叠 | Compose 指定子网是否与已有网络冲突 |

“PC 整理器”页可导出诊断日志，包含最近 200 条 NAS 任务、最近 40 条 PC 任务及每条最多 5000 字符的 PC 日志；PC 离线时仍可导出 NAS 任务和连接错误。导出内容不含配置密钥和 Cookie。PC 显示的耗时是该 PC 任务从创建至当前／完成的时间，包含排队，不等于 NAS 整首入库耗时。需要更完整的容器日志时使用：`docker compose logs --tail=100 ktv`。

企业微信/TG 目前没有内置机器人。后台提供独立凭证和 `GET /api/integrations/reviews`、`POST /api/integrations/reviews/:id`，供自己的集成读取、处理待核对任务。

## 10. 建议验收顺序

本地歌曲播放 → 手机点歌/掌声 → PC 分离一首并切换伴奏 → 纯音频频谱/歌词 → 收藏夹或自动找歌 → 外网播放。

本机 RTX 5080 已跑通真实分离和 NAS 回传；真实歌曲音质、4070 Super、电视硬件和平台下载仍需分别验收。[详细验证记录](VALIDATION.md)。


## v0.2.0 曲库整理变化

编辑期间若另一窗口或后台更新歌曲，页面会保留草稿并提示冲突；比较后选择采用最新资料，或明确保留草稿再保存。批量刷新会逐首显示结果。移出曲库的歌曲可以在“已隐藏”页恢复。

补 MV 前需要试听确认同一录音版本并填写画面偏移，已有原唱、伴奏和歌词会保留。画面候选可以确认、拒绝或重新搜索。歌词支持手动 LRC 和可配置的本地中文索引，配置见 [开发说明](DEVELOPMENT.md)。

设置页可配置纯音频播放时的背景图片轮播。若设备阻止自动出声，点击播放器的重试／开启声音入口；音频不可用时会显示具体错误。

### v0.3.5 高清、歌词与遥控器

打开 B站视频预览后，可选择“最高可用”或列出的清晰度上限，切换后原来的片段标记保留。页面显示当前预览画质；若高清编码不适合浏览器，会使用兼容档位试听，下载仍按选择获取。开启大会员后，在“设置与任务 → 在线资源”的 B站 Cookie 输入框保存该账号最新 Cookie；只在 B站网页登录不会同步给 NAS。不要把 Cookie 发给他人。实际清晰度由片源和当前账号权限决定，不保证每首视频都有 4K。选完高清再加入曲库，已有低清文件不会自动变清晰。

需要一起更新 NAS 和 PC 整理器才能在转换画面时保留源分辨率。如果电视不适合播放 4K，可选择 1080p。后台在转换／校验阶段显示该步骤的实际百分比；每条任务有独立阶段，不代表整批任务完成比例。

歌词按钮左右各有 0.5 秒、3 秒、10 秒，支持提前与延后，累计最多 30 秒，按“复位”恢复。TV 的方向键在按钮之间移动；只有演唱画面获得焦点时，左右键才按 0.1 秒微调。选中画面按确认键全屏，或者向下选择“全屏”，返回键退出全屏。请安装本次新版 TV APK，以使用焦点恢复改进。


## v0.3.6 高清下载与已有歌曲升级

在管理端“在线找歌”点击“扫码登录B站”，用哔哩哔哩App扫描并确认。这里登录后，在线找歌和收藏夹同步共用同一账号；只在浏览器登录B站不会更新NAS凭证。显示登录已过期时请重新扫码，也可以在在线资源设置更新原有bili-sync字段。

选择“最高画质”会下载当前账号可访问的最高画面，并至少要求720p；部分画质需要大会员和片源支持。取不到所选清晰度会提示，不会自动用480p冒充高清。原视频只有低清时，可明确选择480p或360p继续。

已整理过的在线歌曲，如果保留了原视频和裁剪记录，曲库会显示“升级高清画面”。此操作沿用原区间，保留现有原唱、伴奏和歌词，不必再做人声分离。缺少可靠记录时请使用原有替换视频流程并试听核对版本。

新版PC在分离完成后可提供人声起点供保守自动歌词校准；只在多句支持同一个偏移时应用。曲库编辑中可恢复校准前的歌词，手动歌词或已手动微调的歌曲会跳过。没有歌词时播放画面保持清爽。

“重新识别歌名与歌手”会批量更新歌曲名称；“刷新列表”只重新读取状态，列表仍每10秒自动刷新。后台显示的真实画面高度可用于检查下载结果。

## v0.3.6 电视扫码登录与返回退出

电视首次仍需填写NAS地址；连接后直接显示登录二维码。手机扫码，在手机上验证管理密码，核对电视连接码并确认，电视自动进入歌房，手机继续点歌。已经加入当前歌房的手机只需确认。二维码三分钟有效，可在电视刷新；管理密码不会回传保存在电视。

返回键依次关闭弹层或全屏、清除筛选、回到音乐现场。主界面再按返回会提示退出，2.5秒内再按一次关闭APK；不会清空曲库或退出手机登录。菜单键仍可修改NAS地址。
